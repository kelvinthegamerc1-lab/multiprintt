URL Manager
Estas bases sirven para resolver URLs relativas. Las URLs completas que ya tenga un elemento no se modifican. API es opcional: déjala vacía si tu alojamiento solo entrega imágenes/vídeos y no tienes una API propia.
Site
Sitio principal. Ej.: https://multiprintt.com
Media
Base general de multimedia. Respaldo para imágenes/vídeos.
Media Proxy (recomendado)
URL pública de tu Worker/CDN proxy para ocultar GitHub/Cloudinary en Network.
Imágenes
Base específica para imágenes. Ej.: /images/
Vídeos
Base específica para vídeos. Ej.: /videos/
API (opcional)
Solo para endpoints/API externos. No es necesaria para alojar imágenes o vídeos.
Ejemplos rápidos
Cloudflare R2 / CDN propio: Media = https://cdn.tudominio.com/ · Imágenes = https://cdn.tudominio.com/images/ · Vídeos = https://cdn.tudominio.com/videos/ · API = vacío si no existe API.
Cloudinary: normalmente se usan URLs de entrega específicas para imágenes y vídeos; no necesitas una API para mostrar recursos públicos.
